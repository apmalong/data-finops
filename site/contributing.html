Contributing

This site is for people who run data-finops. The documents for people who build it live in the repository, where they stay authoritative:

  • AGENTS.md: how development works, and the engineering rules.
  • GLOSSARY.md: the domain language every page uses.
  • Specifications: what each part of data-finops must do.
  • Decision records: the architecture decisions and why they were made.
  • Plan: the milestones and their exit criteria.
  • Progress: how each milestone was verified.
  • Research: standards, reuse decisions and reviews.

Tasks live in GitHub Issues. To change this site, edit the page in site/, then run python -m scripts.site build and python -m scripts.site check.

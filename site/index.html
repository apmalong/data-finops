data-finops

data-finops allocates a cloud bill to the Query Executions, dbt Model Executions and Workload Runs that caused it. The bill stays authoritative: every amount it allocates reconciles to a Billing Line, and every estimate says how confident it is.

This documentation is for people who run data-finops. It has four parts:

  • Tutorials: learn data-finops by allocating a bill, step by step.
  • How-to guides: get one task done, such as loading a bill or serving the API.
  • Reference: look up commands, routes, data contracts and terms.
  • Explanation: understand why data-finops works the way it does.

To work on data-finops itself, start at Contributing.

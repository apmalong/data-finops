data-finops

data-finops allocates a cloud bill to the queries, dbt models and pipeline runs that caused it. The bill stays authoritative: every amount it allocates reconciles to a Billing Line, and every estimate says how confident it is.

This documentation is for people who run data-finops. It is organised in four parts: tutorials to learn, how-to guides for tasks, reference to look things up, and explanation to understand the design. The parts are being written now.

The site describes the main branch. Nothing is released yet, and a license has not been chosen. The source is on GitHub.

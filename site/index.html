    data-finops

    data-finops allocates a cloud bill to the Query Executions, dbt Model Executions and Workload Runs that caused it. The bill stays authoritative: every amount it allocates reconciles to a Billing Line, and every estimate says how confident it is.

    It runs on your machine. It can also run as a Deployment in your own AWS account, which collects the bill and the workload metadata one time each day. See Deployment architecture.

    To see it on a real bill, look at the Public Demo: the dashboard of a real Deployment. Its workload is simulated, but its Athena charges are real and reconciled to the bill. To see how it compares with the cost tools of AWS, read Compared with AWS's cost tools.

    This documentation is for people who run data-finops. It has four parts:

    • Tutorials: learn data-finops: allocate a bill, step by step.
    • How-to guides: do one task, for example load a bill or serve the API.
    • Reference: look up commands, routes, data contracts and terms.
    • Explanation: understand why data-finops works the way it does.

    To work on data-finops itself, start at Contribute to data-finops.

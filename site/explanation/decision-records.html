Decision records

Each significant design decision is an architecture decision record (ADR) in docs/adr/. A decision is never changed silently. A later ADR refines, amends or replaces it, or an amendment is added to the ADR itself, and its status says so. The ADRs are authoritative. This page only lists them, and a test checks that it lists every one, with the title and status its file gives.

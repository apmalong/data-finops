    Compared with AWS's cost tools

    On this page

    • The questions
    • The tools
    • What the documentation says
    • Where AWS is better
    • Results

    AWS has its own cost tools. This page compares data-finops with them, for the one question that data-finops answers. What did each query, dbt model and Airflow DAG run cost, reconciled to the bill? It also says where AWS is better. The method is in spec 09, and the facts about each AWS tool, with their sources, are in the research note (checked on 2026-11-07).

    The evaluation is not done yet. It starts when the Public Demo has run for 7 days (#232). Until then, this page gives the method and what the AWS documentation says. It does not give results.

    The questions

    Each tool gets the same questions, on the same 7 days of the Public Demo:

    1. What did a dbt model cost last week?
    2. What did an Airflow DAG run cost?
    3. Which queries drove the bill of a workgroup?
    4. How much of the Athena bill is explained, and with what Confidence?
    5. Does every allocated cent reconcile to the invoice?
    6. What did each team and each tenant cost, reconciled?

    The tools

    • Cost Explorer, with Cost Categories and tags.
    • The query history in the Athena console.
    • The FOCUS export, queried with Athena SQL.
    • Cloud Intelligence Dashboards, from their documentation only. They require QuickSight, which costs money each month.
    • data-finops, through the Public Demo and its API.

    For each tool and question, the evaluation records what the tool can answer and at what granularity. It also records how the answer reconciles to the bill, and what the tool costs.

    What the documentation says

    From the AWS documentation, before the evaluation:

    • The finest unit is the workgroup. Athena can tag workgroups, but not queries. Cost Explorer and the FOCUS export thus stop at the workgroup. A cost below the workgroup, for example for a dbt model, must be built from the bill and the query metadata.
    • No AWS tool links cost to dbt or Airflow. The Athena console shows the bytes that each query scanned, but not its cost, and not a reconciliation to the bill. Athena keeps the query history for 45 days.

    data-finops goes further. It splits each Billing Line among the Query Executions in its scope, and rolls them up to Model Executions and Workload Runs through explicit Evidence. Each Allocation states its Confidence and Coverage. Each Billing Line reconciles exactly.

    The evaluation checks each of these statements on the demo.

    Where AWS is better

    • Breadth. The AWS tools cover each service: S3, Glue, compute and more. data-finops covers only the cost of Athena queries that are charged by the data that they scan.
    • Maturity. AWS has commitments and discounts (Savings Plans, Reserved Instances), forecasts, anomaly detection, budgets and multi-account views. data-finops has none of these.
    • No build. The AWS tools are already in the account. If one workgroup for each team answers your question, Cost Explorer with workgroup tags can be sufficient.

    Neither data-finops nor AWS splits the cost of Athena provisioned capacity or Athena for Spark among queries.

Ingest a FOCUS export

This guide loads an Export Snapshot into a database file: all the Billing Lines of one billing account, Billing Period and source, as the provider published them. It comes from a FOCUS JSON file or from an AWS Data Exports Delivery.

Load an Export Snapshot from a JSON file

data-finops ingest focus fixtures/focus/export-2026-10.json --db finops.sqlite
focus: new aws-focus-123456789012-2026-10-v1

The database file is created if it does not exist. The line gives the outcome, then the Export Snapshot's ID:

  • new: it is stored, and it is now the current Export Snapshot of its Snapshot Scope.
  • superseded: it is stored as a Superseded Snapshot, because a later publication of the same Snapshot Scope is current.
  • replay: nothing is stored, because the same content is already there.

Load it again safely

data-finops ingest focus fixtures/focus/export-2026-10.json --db finops.sqlite
focus: replay aws-focus-123456789012-2026-10-v1

A replay stores nothing, so you can rerun an ingest without making copies. Which Export Snapshot is current depends on the provider's publication time, never on the order you load them in (ADR 0020).

Load an AWS Data Exports Delivery

AWS Data Exports writes each Delivery as a manifest, <export>-Manifest.json, and its data files. Download both, then give ingest focus the manifest:

data-finops ingest focus <download-dir>/<export>-Manifest.json --data-dir <data-files-dir> --db finops.sqlite

Not run on this page: it needs a Delivery downloaded from AWS.

  • --data-dir names where the data files were downloaded. Leave it out when they are beside the manifest.
  • The publication time comes from the manifest, never from file times or the time you load it.

If the ingest is refused

Nothing is stored, and the command exits with 2:

  • The file is not a FOCUS Export Snapshot, or the Delivery is not usable. The message names the file, never its content.
  • An Export Snapshot with the same ID is already stored with other content. Stored Export Snapshots never change.

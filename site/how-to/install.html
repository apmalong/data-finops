Install data-finops

On this page

  • What you need
  • Install with the API and dashboard
  • Install without the extra
  • Try it with the demo

This guide installs the data-finops command from a source checkout. Nothing is released yet, so there is no package on PyPI to install.

Not run on this page: it changes your machine.

What you need

  • Python 3.12 or later.
  • uv, which installs the pinned dependencies.
  • git, to clone the repository.

Install with the API and dashboard

git clone https://github.com/apmalong/data-finops.git
cd data-finops
uv sync --extra api --frozen
uv run data-finops --help
git clone https://github.com/apmalong/data-finops.git
cd data-finops
uv sync --extra api --frozen
uv run data-finops --help

The api extra adds FastAPI and uvicorn. serve and demo need them to run the API, the dashboard and the OpenLineage receiver. --frozen installs exactly the versions in uv.lock.

Install without the extra

uv sync --frozen
uv sync --frozen

The base package can ingest and calculate. serve and demo exit with 2 and say that the API needs the api extra. demo checks this before writing anything. Install it with uv sync --extra api --frozen.

Try it with the demo

uv run data-finops demo
uv run data-finops demo

demo loads the hand-written fixtures into a temporary database file, runs a Calculation Run and serves on loopback at http://127.0.0.1:8000/. It reads the repository's fixtures/ directory, so it needs a source checkout: an installed package does not include the fixtures. The database file is removed when demo stops.

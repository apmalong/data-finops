    Every data-finops command, with its usage and its arguments. This page is generated from the command line's own parser, so it says what data-finops --help says. Run data-finops <command> --help for the same text in a terminal.

    --db names the database file that each command reads and writes. The first use creates the file. serve requires the optional api extra.

    Load billing and workload inputs, then allocate the bill.

    data-finops ingest

    load one input file into a database

    Commands: data-finops ingest focus, data-finops ingest openlineage, data-finops ingest dbt, data-finops ingest athena.

    data-finops ingest focus

    a FOCUS Export Snapshot (JSON), or an AWS Data Exports Delivery by its downloaded <export>-Manifest.json

    usage: data-finops ingest focus [-h] [--data-dir DATA_DIR] --db DB path
    ArgumentRequiredDefaultMeaning
    pathrequired
    --data-dir DATA_DIRoptionalwhere a Delivery's data files were downloaded (default: beside its manifest)
    --db DBrequiredthe database file

    usage: data-finops ingest openlineage [-h] --db DB path
    ArgumentRequiredDefaultMeaning

    data-finops collect

    run one Collection Run against AWS into a database (spec 08)

    usage: data-finops collect [-h] --db DB --config CONFIG
                           [--dimensions DIMENSIONS]
    ArgumentRequiredDefaultMeaning
    --db DBrequiredthe database file
    --config CONFIGrequiredthe collector's settings file (TOML)
    --dimensions DIMENSIONSoptionalthe Cost Dimensions file (TOML). Without it, no dimensions apply.

    data-finops serve

    serve the API and dashboard over a database

    usage: data-finops serve [-h] --db DB [--host HOST] [--port PORT]
                         [--token-file TOKEN_FILE]
                         [--explanation-detail {full,minimal}]
    ArgumentRequiredDefaultMeaning
    --db DBrequiredthe database file
    --host HOSToptional127.0.0.1default: loopback only
    --port PORToptional8000
    --token-file TOKEN_FILEoptionala file with the bearer token (or set DATA_FINOPS_TOKEN). Required off loopback.
    --explanation-detail EXPLANATION_DETAILoptionalfullhow much of the Billing Line a Cost Explanation shows (ADR 0028). One of full, minimal.

    data-finops summary

    the Cost Summary of each Snapshot Scope (GET /v1/costs/summary)

    usage: data-finops summary [-h]
                           [--cost-basis {BilledCost,EffectiveCost,ListCost,ContractedCost}]
                           [--billing-account-id BILLING_ACCOUNT_ID]
                           [--billing-period BILLING_PERIOD]
                           (--db DB | --deployment NAME)
                           [--format {table,json}]
    ArgumentRequiredDefaultMeaning
    --cost-basis COST_BASISoptionalBilledCostOne of BilledCost, EffectiveCost, ListCost, ContractedCost.
    --billing-account-id BILLING_ACCOUNT_IDoptional
    --billing-period BILLING_PERIODoptionalthe first day of the period (YYYY-MM-DD)
    --db DBone of --db, --deploymenta local database file
    --deployment NAMEone of --db, --deploymenta Deployment: the table [NAME] in ~/.data-finops/deployments.toml, with api_url, region and profile
    --format FORMAToptionaltabledefault: table One of table, json.

                               [--source SOURCE] [--target-id TARGET_ID]
                               [--category {direct,shared,idle,unallocated}]
                               [--billing-line-ref BILLING_LINE_REF]
                               [--cost-basis {BilledCost,EffectiveCost,ListCost,ContractedCost}]
                               [--limit LIMIT] [--offset OFFSET]
                               (--db DB | --deployment NAME)
                               [--format {table,json}]
    ArgumentRequiredDefaultMeaning

    --billing-account-id BILLING_ACCOUNT_IDoptional
    --billing-period BILLING_PERIODoptionalthe first day of the period (YYYY-MM-DD)
    --source SOURCEoptionalthe source of the Export Snapshot
    --target-id TARGET_IDoptional
    --category CATEGORYoptionalOne of direct, shared, idle, unallocated.
    --billing-line-ref BILLING_LINE_REFoptional
    --cost-basis COST_BASISoptionaldefault: each Cost Basis One of BilledCost, EffectiveCost, ListCost, ContractedCost.
    --limit LIMIToptional1001 to 1000
    --offset OFFSEToptional0
    --db DBone of --db, --deploymenta local database file
    --deployment NAMEone of --db, --deploymenta Deployment: the table [NAME] in ~/.data-finops/deployments.toml, with api_url, region and profile
    --format FORMAToptionaltabledefault: table One of table, json.

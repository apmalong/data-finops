Every data-finops command, with its usage and its arguments. This page is generated from the command line's own parser, so it says what data-finops --help says. Run data-finops <command> --help for the same text in a terminal.

--db names the database file every command reads and writes; it is created on first use. serve needs the optional api extra.

Load billing and workload inputs, then allocate the bill.

data-finops ingest

load one input file into a database

Commands: data-finops ingest focus, data-finops ingest openlineage, data-finops ingest dbt, data-finops ingest athena.

data-finops ingest focus

a FOCUS Export Snapshot (JSON), or an AWS Data Exports Delivery by its downloaded <export>-Manifest.json

usage: data-finops ingest focus [-h] [--data-dir DATA_DIR] --db DB path
ArgumentRequiredDefaultMeaning
pathrequired
--data-dir DATA_DIRoptionalwhere a Delivery's data files were downloaded (default: beside its manifest)
--db DBrequiredthe database file

data-finops serve

serve the API and dashboard over a database

usage: data-finops serve [-h] --db DB [--host HOST] [--port PORT]
                         [--token-file TOKEN_FILE]
                         [--explanation-detail {full,minimal}]
ArgumentRequiredDefaultMeaning
--db DBrequiredthe database file
--host HOSToptional127.0.0.1default: loopback only
--port PORToptional8000
--token-file TOKEN_FILEoptionala file holding the bearer token (or set DATA_FINOPS_TOKEN); required off loopback
--explanation-detail EXPLANATION_DETAILoptionalfullhow much of the Billing Line a Cost Explanation shows (ADR 0028). One of full, minimal.

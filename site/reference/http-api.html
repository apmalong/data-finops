HTTP API

Every route that data-finops serve answers, with its parameters and responses. This page is generated from schemas/openapi.json, the OpenAPI 3.1 document the server is tested against.

  • Amounts are Decimal strings, never floating-point numbers.
  • Errors are Problem Details (RFC 9457, application/problem+json). They name the field at fault and never echo what was sent.
  • The server listens on loopback unless told otherwise. With a token configured, every route needs Authorization: Bearer <token>.
  • Lists are paged with limit (default 100, at most 1000) and offset.

POST /api/v1/lineage: Receive Lineage

Store one OpenLineage RunEvent, the default endpoint of OpenLineage's HTTP transport (spec 04). Screened exactly as one item of an event file. The one async endpoint (spec 06): it streams the body so an oversized one is refused at the cap instead of buffered (ADR 0024), then ingests in the thread pool.

Request body: application/json, required.

StatusMeaningBody
201Stored, or already stored (a duplicate).application/json: LineageReceipt
202A JobEvent or DatasetEvent: not stored.application/json: LineageUnsupported
400Rejected: the detail gives the kind and failing field, never content.application/problem+json: Problem Details (RFC 9457)
401When a token is configured: no valid bearer token (ADR 0024).application/problem+json: Problem Details (RFC 9457)
413The body is larger than one event may be (1 MiB).application/problem+json: Problem Details (RFC 9457)

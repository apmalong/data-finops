    • Schemas

    Every route that data-finops serve answers, with its parameters and responses. This page is generated from schemas/openapi.json, the OpenAPI 3.1 document the server is tested against.

    • Amounts are Decimal strings, never floating-point numbers.
    • Errors are Problem Details (RFC 9457, application/problem+json). They name the field at fault and never echo what was sent.
    • The server listens on loopback unless told otherwise. If a token is configured, each route requires Authorization: Bearer <token>.
    • Lists are paged with limit (default 100, at most 1000) and offset.

    POST /api/v1/lineage: Receive Lineage

    Store one OpenLineage RunEvent. This is the default endpoint of the OpenLineage HTTP transport (spec 04). The event is screened exactly as one item of an event file. This is the one async endpoint (spec 06). It reads the body as a stream, so a body over the limit is refused at the limit and not buffered (ADR 0024). Then it ingests the event in the thread pool.

    Request body: application/json, required.

    StatusMeaningBody
    201Stored, or already stored (a duplicate).application/json: LineageReceipt
    202A JobEvent or DatasetEvent: not stored.application/json: LineageUnsupported
    400Rejected: the detail gives the kind and the field that failed, never content.application/problem+json: Problem Details (RFC 9457)
    401When a token is configured: no valid bearer token (ADR 0024).application/problem+json: Problem Details (RFC 9457)
    413The body is larger than the limit for one event (1 MiB).application/problem+json: Problem Details (RFC 9457)
    415The body has a Content-Encoding. Send the event uncompressed.application/problem+json: Problem Details (RFC 9457)
    500An unexpected failure. The detail tells nothing about it.application/problem+json: Problem Details (RFC 9457)
    503The database cannot be opened as a current data-finops database.application/problem+json: Problem Details (RFC 9457)

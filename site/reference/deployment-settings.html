    Deployment settings

    On this page

    • Settings
    • Outputs

    The settings of the AWS Deployment and the outputs of its Pulumi stack. Each setting is a key of the stack's configuration: aws:region, and every other key under data-finops:. A setting left out takes its default. The stack checks every setting before it declares anything, and an error names the setting, never its value.

    This page is generated from the stack's source, deployment/settings.py and deployment/program.py, which are authoritative.

    Settings

    KeyDefaultMeaning
    aws:regionrequiredThe AWS Region to deploy to. The collector reads the Athena workgroups in this Region.
    exportBucketrequiredThe S3 bucket the AWS Data Exports FOCUS export is delivered to. The collector only reads it.
    exportNamerequiredThe name of the FOCUS export, as AWS Data Exports names it.
    workgroupsrequiredThe Athena workgroups whose query history is collected, as a JSON list of names, for example ["primary"]. It must not be empty.
    exportPrefixemptyThe S3 path prefix that the export is delivered under. It is empty when the export has no prefix.
    billingLookbackPeriods2How many Billing Periods each Collection Run lists, back from the current one. A whole number from 1 to 24.
    maxHistoryPages200How many ListQueryExecutions pages each Collection Run reads, per workgroup. A whole number from 1 to 1000.
    schedulecron(0 6 * * ? *)When the Collection Run starts, as an EventBridge Scheduler expression, in UTC.
    collectorTimeoutSeconds900The collector function's timeout, in seconds. A whole number from 1 to 900.
    collectorMemoryMb2048The collector function's memory, in MB. A whole number from 128 to 10240.
    apiTimeoutSeconds30The API function's timeout, in seconds. API Gateway stops a request after 30 seconds, so a longer timeout does not give a request more time. A whole number from 1 to 900.
    apiMemoryMb1024The API function's memory, in MB. A whole number from 128 to 10240.
    ephemeralStorageMb10240The /tmp storage, in MB, of each function that copies the database: the collector, the API and the publisher. The database and each Inbox file must fit in it. Lambda charges for the storage above 512 MB. A whole number from 512 to 10240.
    apiReservedConcurrencyunsetAn optional limit on the concurrent requests of the API function, a whole number of at least 0. 0 switches the API off. New accounts can lack the concurrency quota to reserve any.
    apiRateLimit10The most requests a second that the API accepts, from all callers together. API Gateway answers 429 to more. Set it and apiBurstLimit to 0 to switch the API off (the kill switch). A whole number from 0 to 10000.
    apiBurstLimit20The most requests that the API accepts in one short burst, from all callers together. A whole number from 0 to 5000.
    logRetentionDays30How long both functions' logs are kept, in days: a period CloudWatch Logs accepts, such as 1, 7, 14, 30, 90 or 365.
    noncurrentVersionDays30How long an old version of the database object is kept, in days, before S3 expires it. A whole number from 1 to 3650.
    inboxRetentionDays30How long an object stays in the Inbox, in days, before S3 expires it. A whole number from 1 to 3650.
    kmsKeyArnunsetAn optional customer-managed KMS key ARN to encrypt the bucket with, at about $1 a month. Use the key ARN, arn:aws:kms:<region>:<account>:key/<key id>. An alias ARN is refused, because IAM gives the use of a key only on its key ARN. Unset, the bucket uses the S3-managed key.
    explanationDetailminimalHow much the API's Cost Explanations show: minimal or full (ADR 0028).
    budgetMonthlyUsdunsetAn optional monthly amount, in US dollars, for an account-wide AWS Budget that alerts on forecast and actual spend. AWS Budgets cover the whole account, not just the Deployment. Give it with budgetEmail, or neither.
    budgetEmailunsetThe address the Budget alerts are sent to. Give it with budgetMonthlyUsd, or neither.
    alarmEmailunsetAn optional address to send an alarm to when the collector function reports errors, through an SNS topic.
    deleteDataOnDestroyfalseWhether pulumi destroy deletes the bucket and its data. By default the bucket is kept, with the database and the Inbox in it.
    costDimensionsunsetAn optional path to a Cost Dimensions file (TOML, spec 09). The stack uploads it to config/cost-dimensions.toml in the bucket, and the collector applies it in each Collection Run. Unset, no dimensions apply.
    publicDemofalseWhether the stack also makes the public demo (spec 09). The demo has its own bucket, the data-finops-demo Athena workgroup, the Glue tables of the demo dataset and the dataset generator function. Set it to false and run pulumi up to remove the demo.
    demoScanCutoffBytes1000000000The most bytes one query in the demo workgroup can scan before Athena cancels it. Athena accepts 10 MB or more. A whole number from 10000000 to 1000000000000.
    demoSchedulecron(25 0/6 * * ? *)When the demo's simulated orchestrator starts, in UTC: every six hours, as cron(M H/6 * * ? *). M, from 10 to 40, keeps each query away from the hour (spec 09). H, from 0 to 5, is the first start of the day, which runs daily_orders, and weekly_finance on Mondays. Each start runs hourly_events.

    Outputs

    OutputMeaning
    bucketThe Deployment's S3 bucket: the database, the Inboxes and the Lambda package.
    apiUrlThe API's address, on API Gateway. Requests must be signed with AWS SigV4 (service execute-api) by a principal with the reader, consumer or operator policy.
    producerPolicyArnThe managed policy that lets a producer write to the Inboxes and nothing else. Attach it to whatever sends OpenLineage events or dbt artifacts.
    readerPolicyArnThe managed policy that lets a principal call the API's read routes.
    consumerPolicyArnThe managed policy of the consumer Control Role. For now, it lets a principal call the read routes only.
    operatorPolicyArnThe managed policy of the operator Control Role. For now, it lets a principal call the read routes only.
    collectorFunctionThe collector function's name, for its logs or to invoke a Collection Run by hand.
    apiFunctionThe API function's name, for its logs.
    demoUrlOnly with publicDemo: the public demo's address, on CloudFront.
    demoBucketOnly with publicDemo: the public demo's bucket, with the demo dataset.
    demoGeneratorFunctionOnly with publicDemo: the function that writes the demo dataset. Invoke it one time after the first deploy.
    demoSimulatorFunctionOnly with publicDemo: the simulated orchestrator, which its schedule starts. Invoke it by hand to run the DAGs due now.

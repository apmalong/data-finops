Deployment settings

On this page

  • Settings
  • Outputs

The settings of the AWS Deployment and the outputs of its Pulumi stack. Each setting is a key of the stack's configuration: aws:region, and every other key under data-finops:. A setting left out takes its default. The stack checks every setting before it declares anything, and an error names the setting, never its value.

This page is generated from the stack's source, deployment/settings.py and deployment/program.py, which are authoritative.

Settings

KeyDefaultMeaning
aws:regionrequiredThe AWS Region to deploy to. The collector reads the Athena workgroups in this Region.
exportBucketrequiredThe S3 bucket the AWS Data Exports FOCUS export is delivered to. The collector only reads it.
exportNamerequiredThe name of the FOCUS export, as AWS Data Exports names it.
workgroupsrequiredThe Athena workgroups whose query history is collected, as a JSON list of names, for example ["primary"]. It may not be empty.
exportPrefixemptyThe S3 path prefix the export is delivered under; empty when it has none.
billingLookbackPeriods2How many Billing Periods, counting back from the current one, each Collection Run lists. A whole number from 1 to 24.
maxHistoryPages200How many ListQueryExecutions pages each Collection Run reads, per workgroup. A whole number from 1 to 1000.
schedulecron(0 6 * * ? *)When the Collection Run starts, as an EventBridge Scheduler expression, in UTC.
collectorTimeoutSeconds900The collector function's timeout, in seconds. A whole number from 1 to 900.
collectorMemoryMb2048The collector function's memory, in MB. A whole number from 128 to 10240.
apiTimeoutSeconds30The API function's timeout, in seconds. A whole number from 1 to 900.
apiMemoryMb1024The API function's memory, in MB. A whole number from 128 to 10240.
apiReservedConcurrencyunsetAn optional cap on the API function's concurrent requests, a whole number of at least 0; 0 switches the API off. New accounts may lack the concurrency quota to reserve any.
logRetentionDays30How long both functions' logs are kept, in days: a period CloudWatch Logs accepts, such as 1, 7, 14, 30, 90 or 365.
noncurrentVersionDays30How long an old version of the database object is kept, in days, before S3 expires it. A whole number from 1 to 3650.
inboxRetentionDays30How long an object stays in the Inbox, in days, before S3 expires it. A whole number from 1 to 3650.
kmsKeyArnunsetAn optional customer-managed KMS key ARN to encrypt the bucket with, at about $1 a month. Unset, the bucket uses the S3-managed key.
explanationDetailminimalHow much the API's Cost Explanations show: minimal or full (ADR 0028).
budgetMonthlyUsdunsetAn optional monthly amount, in US dollars, for an account-wide AWS Budget that alerts on forecast and actual spend. AWS Budgets cover the whole account, not just the Deployment. Give it with budgetEmail, or neither.
budgetEmailunsetThe address the Budget alerts are sent to. Give it with budgetMonthlyUsd, or neither.
alarmEmailunsetAn optional address to send an alarm to when the collector function reports errors, through an SNS topic.
deleteDataOnDestroyfalseWhether pulumi destroy deletes the bucket and its data. By default the bucket is kept, with the database and the Inbox in it.

Outputs

OutputMeaning
bucketThe Deployment's S3 bucket: the database, the Inboxes and the Lambda package.
apiUrlThe read-only API's Function URL. Requests must be signed with AWS SigV4 by a principal with the reader policy.
producerPolicyArnThe managed policy that lets a producer write to the Inboxes and nothing else. Attach it to whatever sends OpenLineage events or dbt artifacts.
readerPolicyArnThe managed policy that lets a principal call the API's Function URL.
collectorFunctionThe collector function's name, for its logs or to invoke a Collection Run by hand.
apiFunctionThe API function's name, for its logs.
